Generated by VibePress as a WordPress block theme (public beta).

Install checklist
1. Appearance → Themes → Add New → Upload Theme → select the zip → Activate
2. Settings → Reading → Your homepage displays → A static page (create “Home” if needed) → save
3. Settings → Permalinks → Post name → save (so /page-slug/ works)
4. Replace stock photos where this theme was designed (click a photo → Replace this photo), then download again. Installing a newer zip
   switches to the new design; templates saved in the Site Editor are kept with “backup” in their name
5. Edit the contact button / email (mailto) to your real address
6. Extra pages you designed appear under Pages after first activate, with their design in the page body — open one under Pages and edit it in the block editor

日本語
1. 外観 → テーマ → アップロード → 有効化
2. 設定 → 表示設定 → 固定ページをホームページに
3. 設定 → パーマリンク → 「投稿名」
4. 写真の差し替えはデザインした編集画面で（写真をクリック → Replace this photo）行い、再ダウンロード。新しい ZIP を入れると新デザインに切り替わり、サイトエディターで保存したテンプレートは「backup」付きの名前で残ります
5. 問い合わせボタンのメールアドレスを実アドレスに変更
6. 追加ページは有効化時に自動作成。固定ページ一覧から開き、ブロックエディターでそのまま編集できます
