# Northline Physio — sample WordPress block theme

A sample block theme generated by [VibePress](https://www.getvibepress.com/) from a short brief for a fictional physio clinic in Leeds. No hand edits after generation.

- Block theme with `theme.json`, templates, header/footer template parts and a 404 template
- Six pages: Home, About, Rehabilitation, Fees, Book online, Contact
- Photos are Unsplash placeholders (credits in `readme.txt`)

To try it: download this repo as a ZIP, then in WordPress go to Appearance → Themes → Add New → Upload Theme. See `readme.txt` for the full install checklist.
